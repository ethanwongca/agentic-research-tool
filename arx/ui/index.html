How arx works

  1. Lay out boxes. Each box is a step you design. Press Tab or double-click to add one. Drag from an output socket ● to another box to connect, or into empty space to add a box that's already connected.
  2. Specify each box: purpose, approach, decisions and constraints, a typed contract, and checks.
  3. Approve. Only approved boxes can be built, and the agent implements exactly what you wrote.
  4. Build. Click Build with Claude or Build with Codex, or run /arx-build in Claude Code.
  5. Checks pass → the box locks. If it keeps failing, it comes back to you.
